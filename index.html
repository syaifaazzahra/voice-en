Latihan Ngobrol Inggris 🎙️

Ngobrol pakai suara dengan tutor AI: kamu ngomong, transkripnya dikirim ke tutor, jawabannya dibacakan kembali. Pakai API key milikmu sendiri — Google Gemini, atau provider OpenAI Compatible dengan URL custom.

  1. Buka aistudio.google.com/apikey dan login dengan akun Google.
  2. Klik Create API key — gratis, tanpa kartu kredit, bukan subscription.
  3. Salin key-nya, lalu tempel di bawah ini.

Contoh: https://api.openai.com/v1, endpoint provider OpenAI-compatible lain, atau http://localhost:11434/v1 untuk Ollama lokal. Harus https://, atau http://localhost untuk server lokal.

Bila diisi, dikirim sebagai header Authorization: Bearer.

Ollama lokal: jalankan dengan OLLAMA_ORIGINS=* (mis. OLLAMA_ORIGINS=* ollama serve) supaya browser diizinkan mengaksesnya (CORS).

🔒 Privasi: semua API key hanya tersimpan di browser ini (localStorage) dan hanya dikirim ke API penyedia yang kamu pilih (Google Gemini, atau Base URL OpenAI Compatible milikmu). Suara & teks obrolanmu juga hanya pergi ke penyedia itu — tidak ada server perantara, dan tidak ada yang dibagikan antar pengunjung; setiap orang menjalankan halaman ini sendiri-sendiri.

Dapatkan key gratis di aistudio.google.com/apikey

Saat aktif, panel log kecil muncul di bawah area obrolan dan mencatat setiap event pengenalan suara mentah dari browser (timestamp, jumlah hasil, dan isi tiap slot) — berguna untuk mendiagnosis transkrip yang berulang/duplikat. Log hanya tampil di layar dan hilang saat halaman ditutup; toggle ini langsung aktif tanpa perlu klik Simpan.

🎙️ Mode fallback “Suara AI”: kalau suara bawaan browser tidak tersedia (daftar suara kosong) atau pengenalan suara browser gagal, halaman ini otomatis memakai Gemini untuk membacakan jawaban tutor dan mentranskrip suaramu lewat tombol mic mode rekam. Mode fallback ini memakai kuota API key kamu — dan hanya aktif saat fitur suara bawaan browser tidak jalan. Fallback Suara AI selalu memakai Gemini API key di atas, apa pun Penyedia AI yang dipilih — yang mengikuti penyedia terpilih hanya percakapan teksnya.
