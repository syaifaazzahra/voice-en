Latihan Ngobrol Inggris 🎙️

Ngobrol pakai suara dengan tutor AI: kamu ngomong, transkripnya dikirim ke Gemini, jawabannya dibacakan kembali. Gratis — pakai API key Gemini milikmu sendiri.

  1. Buka aistudio.google.com/apikey dan login dengan akun Google.
  2. Klik Create API key — gratis, tanpa kartu kredit, bukan subscription.
  3. Salin key-nya, lalu tempel di bawah ini.

🔒 Privasi: API key hanya tersimpan di browser ini (localStorage) dan tidak pernah dikirim ke mana pun selain panggilan langsung ke API Google. Suara & teks obrolanmu juga hanya pergi ke Google — tidak ada server perantara, dan tidak ada yang dibagikan antar pengunjung; setiap orang menjalankan halaman ini sendiri-sendiri.

Pengaturan

Ganti API key atau model Gemini yang dipakai.

Dapatkan key gratis di aistudio.google.com/apikey

🎙️ Mode fallback “Suara AI”: kalau suara bawaan browser tidak tersedia (daftar suara kosong) atau pengenalan suara browser gagal, halaman ini otomatis memakai Gemini untuk membacakan jawaban tutor dan mentranskrip suaramu lewat tombol mic mode rekam. Mode fallback ini memakai kuota API key kamu — dan hanya aktif saat fitur suara bawaan browser tidak jalan.
